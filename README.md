# Atividades Java

Abra a pasta `AtividadesJava` no IntelliJ IDEA. Este é um único projeto Java, com um único módulo e uma única pasta de código: `src/`.

As atividades estão separadas dentro de `src/`, mantendo os nomes originais:

- `javacriandosuaprimeiraaplicacao/`
- `aplicandoorientacaoobjetos/`
- `listaecolecoesdedados/`
- `javaconsumindoAPIgravandoarquivoselidandocomerros/`
- `exerciciosaulafaculdade/`

Cada pasta representa uma atividade. Os pacotes impedem que classes de atividades diferentes — por exemplo, vários arquivos `Main.java` — tenham conflito.
